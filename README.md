# Xerox WorkCentre 3025 on Apple Silicon

Independent open-source integration for the **WorkCentre 3025 BI**: native
scanning through Apple's existing interfaces, with an optional toner display
correction. No companion app, Rosetta, legacy Xerox package or VueScan is used.

The scanner service combines the official SANE `xerox_mfp` backend with AirSane.
Local patches address demonstrated TCP framing, crop, image encoding and
cancellation problems. Bonjour discovery follows the printer's stable hardware
UUID rather than a fixed IP address. Printing retains the existing AirPrint queue.

| Component | Purpose | Status |
|---|---|---|
| Scanner bridge | Background ARM64 SANE → eSCL service, loopback port 18325 | Acquired real documents through all three Apple routes on one Mac |
| Queue association | Adds the scanner fields generated by macOS to the preserved queue | Accepted on the original queue; requires a local review |
| Optional [toner proxy](experiments/ipp-supply-proxy/INSTALLATION.md) | Corrects white toner-color metadata to black; preserves reported level | Native Supply Levels and physical printing accepted on one Mac |
| Optional [document workflows](experiments/native-documents/README.md) | Booklet, card composition, interleaving, empty-page removal and optional deskew in Apple PDF/Finder workflows | Offline tests passed; visible menu and physical refeed acceptance outstanding |
| Scanner profile experiment | Additional eSCL profile compatibility investigation | Uninstalled; not part of the production build |

The three scanner access paths were tested separately: the preserved Xerox
entry's **Open Scanner / Print Center Scanner** button, **Image Capture**, and
**Preview → File → Import from Xerox**. On the tested macOS version, the first
route opens Image Capture. Controls differ between Apple applications.

**This is a source project with a working single-device baseline, not a generally
qualified or notarized driver release.** Historical hardware acceptance was on
macOS 26.6.2, Apple Silicon, a BI flatbed and Wi-Fi. See [status and limits](docs/STATUS.md).
No future macOS compatibility is promised; no ADF, fax or automatic duplex is
advertised for BI hardware. This build supports network scanning only: USB
scanning and USB hotplug are disabled. 1200 dpi scanning remains unqualified.

## Build and install

Start with [BUILD.md](docs/BUILD.md), then review the generated package and
[queue association procedure](docs/QUEUE_ASSOCIATION.md). Builds stay inside the
checkout. Installation is a separate, explicit step. Runtime components are
checked for ARM64 and locally signed; Developer ID signing/notarization is absent.

Create your own private identity file from
[`packaging/device.example.json`](packaging/device.example.json). The example is
synthetic. Never use it to impersonate another printer. No owner's identity,
scans, diagnostic logs, firmware images or generated installers are in Git.
Device-specific installers contain their configured identity and should stay private.

The optional toner proxy changes only the existing queue's device URI to a local
service at port 18326. Printing then depends on that service. Its uninstaller
restores the original direct connection before stopping it. Install scanner
first, toner second; remove toner first. Source checkout deletion is not an
uninstaller. Run `./uninstall-all` from the generated scanner package, or
`bash packaging/uninstall-all` from this checkout, to remove both components in
the correct order while preserving the printer queue and user documents. The
combined helper is not copied into the installed runtime; each component keeps
its own uninstaller under `~/Library/Application Support/`.

## Independent use and publication

The scanner and toner packages were built from a fresh source export and passed
isolated install/uninstall checks on 11 October 2026. All 11 packaged runtime
binaries were ARM64. See [the verification record](docs/PUBLIC_READINESS.md).
Another Mac still needs the listed build tools, its own printer identity, local
network permission where requested, and native queue-association verification.
There is no preconfigured, notarized download or universal hardware guarantee.

Only tracked source belongs on GitHub. Ignored `private/`, `evidence/`, device
configuration and generated packages may contain personal information; do not
upload a ZIP of an entire working directory. The old development workspace is
not a build or runtime dependency.

## Development

Run `python3 scripts/check.py` for source-export privacy, queue preservation,
proxy lifecycle and native TCP tests without accessing the printer. See
[TESTING.md](docs/TESTING.md) for optional builds and physical acceptance gates.
The explicit source archive list is [`source-files.txt`](source-files.txt);
update it when adding production sources. A scanner binary package includes
corresponding upstream sources, patches, build scripts and license notices.

[SpliX](docs/SPLIX.md) supports **printing** on the 3025. It may be useful for
additional print controls, but does not replace this scanner integration. It is
not installed or selected by this project.
